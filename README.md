# Verba et Acta

*Verba et Acta compares what apps' terms and privacy policies say with what the apps actually do. Reports are written in Korean.*

앱의 약관·개인정보 처리방침이 말하는 것(verba)과 앱이 실제로 하는 것(acta)을 비교해 기록합니다. 개인이 운영합니다.

## 원칙

1. **분석 범위** — 직접 설치한 앱의 정적 분석과 공개 문서 비교만 합니다. 서버 접속 시도, 타인 계정 접근, 인증 우회는 하지 않습니다.
2. **서술 기준** — 확인된 사실과 확인하지 못한 사항을 구분해 적습니다. 위법 여부는 판단하지 않습니다.
3. **취약점** — 악용될 수 있는 보안 취약점은 공개하지 않고 해당 회사나 KISA에 먼저 알립니다.
4. **반론과 정정** — 회사의 설명이나 반론은 받은 대로 싣습니다. 오류는 지우지 않고 고친 뒤 수정 내역을 남깁니다.
5. **요청** — 분석 요청은 받지만, 개인을 대상으로 한 분석, 유출 자료 분석, 대가를 받는 분석은 하지 않습니다.
